# Changelog

### Características añadidas
- Búsqueda automática de aplicaciones AppImages en línea

- Comando de información detallada de aplicaciones

### Características iniciales
- Instalación de aplicaciones AppImage

- Soporte para modos de instalación usuario y sistema
- Registro de aplicaciones instaladas
