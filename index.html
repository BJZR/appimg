appimg

Gestor minimalista de AppImage para Linux

bash <(curl -s https://raw.githubusercontent.com/bjzr/appimg/main/scripts/install.sh)

Características

📦 Instalación desde URL o archivo local
🔍 Búsqueda en AppImageHub
🧑‍💻 Modo usuario (sin sudo) o sistema
📋 Registro de aplicaciones instaladas
🔄 Actualización y eliminación
✅ Verificación SHA256

Comandos

ComandoDescripción
installInstalar una AppImage
updateRe-descargar y actualizar
removeDesinstalar completamente
listListar todas las instaladas
searchBuscar en AppImageHub
infoDetalles de una app
statusVer si está instalada
autoupdateVerificar actualizaciones

Uso rápido

appimg search obsidian
appimg install obsidian
appimg list
appimg info obsidian
